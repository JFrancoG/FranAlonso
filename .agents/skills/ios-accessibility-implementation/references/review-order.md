# Fast review order

1. Structure: names, roles, values, grouping, headings and reading order.
2. Operation: touch target, focus, keyboard, Voice Control, Switch Control and gesture alternatives.
3. Perception: Dynamic Type, contrast, color independence, motion and transparency.
4. Adaptation: orientation, window size, iPhone/iPad, localization and RTL.
5. Feedback: errors, loading, status announcements, confirmation and focus restoration.
6. Evidence: tests, previews, Inspector, manual pass, findings and reviewer result.

For the ADR 0029 functional demo gate, apply this order to static/focused checks and representative affected previews.
Retain existing evidence and record deferred exhaustive/manual checks or known defects in the linked issue, with owner
and recovery trigger after feedback and flow stabilization, before the first candidate for real use. Keep their
`Falla`, `Pendiente` or `Limitado` results; integral validation remains pending until supported by evidence.
