# Closeout output

Report:

- What changed and what remained out of scope.
- Build, tests, diagnostics and TDD evidence.
- Preview and accessibility evidence, including manual limitations.
- Delivery gate evaluated: functional demo or integral validation. For ADR 0029, include the linked accessibility
  issue, owner, retained evidence, deferred `Falla`/`Pendiente`/`Limitado` items and recovery trigger before real use.
- Specialist audit results and any reruns.
- Documentation and Linear reconciliation.
- Current Git state and the exact delivery action performed or still awaiting authorization.
- Remaining work, blockers and next approved gate.

State subphase and phase status separately. A functional subphase closure does not close a phase with integral
accessibility validation pending.
