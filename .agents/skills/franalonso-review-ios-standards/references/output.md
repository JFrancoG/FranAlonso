# Review output

Lead with findings ordered P0–P3. Each finding includes imperative title, absolute file and line, violated authority,
evidence, impact and smallest recommended direction without a patch.

Then report:

- Scope and diff audited.
- Repository and primary sources checked.
- Build/tests/diagnostics evidence inspected or missing.
- Out-of-scope observations.
- Residual risks and gate result: pass, correct before proceeding, or blocked.

If there are no findings, say `Sin hallazgos` without claiming absolute correctness beyond the evidence.
